## 操作方法

### コントローラー

| 操作 | 入力 |
|---|---|
| 選択・移動 | 左スティック |
| 決定・ライトなどを持つ | Aボタン |
| キャンセル・メニュー | Bボタン |

### キーボード

| 操作 | 1P | 2P |
|---|---|---|
| 選択・移動 | WASD | 方向キー |
| 決定・ライトなどを持つ | Enter | Enter + 右Shift |
| キャンセル・メニュー | BackSpace | BackSpace |

## プレイヤーのルール

### 1P
- 赤い丸で表示され、アニメーションに数字が表示されます。
- 赤い光の中でしか行動できません。

### 2P
- 青い丸で表示されます。
- 赤い光に触れてはいけません。
